一、專題介紹

用途、使用對象與核心功能

  • 專題名稱：大學生報告主題發想_搜集機器人（IdeaCatcher Bot）
  • 使用對象：大專院校學生、常需進行期末專題、分組討論或學期論文的同學。
  • 想解決的問題：大學生在日常通勤、走路、滑社群或睡前常靈光一閃冒出絕佳報告主題，但往往因為手邊沒專門工具或備忘錄散落，導致「點子常飛掉」。本 Bot 讓同學在最常用的 LINE 中即時隨手一句話記錄，並自動分類整理。
  • 核心功能：收到點子後即時記錄內容、進行智慧學科歸類，並提供隨時調閱、領域篩選與編號刪除管理。

四、AI 協作

使用工具、代表性指令與檢查修正 AI 的真實經驗

  • 使用 AI 工具：Antigravity Agent (Google DeepMind)。
  • 代表性提示指令 (Prompt)：
    「請依照我的 LINE Bot 專題資料，升級 bot.py 加入智慧關鍵字自動分類、領域篩選與單筆刪除功能，並加入嚴格的防呆捕捉與自動化測試腳本。」
  • 檢查或修正 AI 產出的真實經驗（重要評量重點）：
    【真實經驗 1：修正 Git 初始化與目錄架構】
    最初 AI 在背景嘗試直接執行 git add，但遇到 macOS 沙盒權限確認。我察覺此資料夾應全新獨立管理，因此按下拒絕，並主動指示 AI「GIPINIT這個新的資料夾」，促使 AI 在獨立的「嘻嘻」資料夾中重新建立乾淨的 Git 倉庫，並於外層加入 .gitignore 隔離，有效避免兩個專案衝突。

    【真實經驗 2：堅持真實性原則，杜絕虛構】
    我特別要求 AI：「裡面的內容若有缺漏請不要自行編造，請詢問我讓我補上。」促使 AI 主動全面盤點專案中的外部連結、姓名學號與個人心得，凡未確認者一律標註「待補」，落實了嚴謹求實的工程態度。
