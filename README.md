# 大學生報告主題發想_搜集機器人 (IdeaCatcher Bot)

> 專為大學生設計的 LINE Bot，解決日常生活點子突發奇想卻稍縱即逝的困擾。

---

## 🔍 每一步驟與檔案在做什麼？（逐步解說）

### 步驟 1：撰寫專題計畫書 (`PROJECT_PLAN.md`)
* **目的**：嚴格依照作業規定「六大必填項目」，撰寫半頁至一頁的正式提案。
* **內容涵蓋**：
  1. **專題名稱**：大學生報告主題發想_搜集機器人
  2. **使用對象與用途**：針對常需要寫報告的大學生，捕捉隨時冒出的靈感。
  3. **核心功能**：即時解析使用者輸入，自動提取「主題」與「學科領域分類」，並支援歷史調閱。
  4. **對話範例**：包含正常記錄、調閱清單，以及空白輸入時的防呆提示。
  5. **AI 協助方式**：說明 AI Agent 協同寫程式、除錯、生成測試與製作網頁之分工。
  6. **測試計畫**：條列三組具體測試輸入、預期結果與驗證標準。

### 步驟 2：實作核心訊息處理邏輯 (`bot.py`)
* **目的**：提供具備狀態管理、正規表達式解析與防呆機制的 Python 類別 `IdeaBot`。
* **核心解析原理**：
  * 使用正規表達式匹配 `靈感：` 或 `記：` 開頭。
  * 自動判斷後續是否附帶 `分類：[領域]`（如 `社會心理`、`資工`、`醫學`），若無指定則預設為 `一般/未分類`。
  * 防呆機制：若「靈感：」後為空字串或純空格，不寫入任何資料，並回傳格式提醒教學。
  * 提供「查看靈感」與「清空靈感」功能。
* **本機直接試玩**：
  ```bash
  python3 bot.py
  ```

### 步驟 3：建立測試計畫與自動化驗證 (`test_bot.py`)
* **目的**：符合課堂「測試寫出輸入、預期與實際結果」之評分重點。
* **執行測試並產生報告**：
  ```bash
  python3 test_bot.py
  ```
  執行後會即時驗證：
  1. **情境 1**：正常完整記錄（檢查主題、分類與資料庫長度）。
  2. **情境 2**：輸入不完整（檢查是否攔截空白，且不增加無效項目）。
  3. **情境 3**：調閱清單與未支援指令（檢查清單輸出格式與未知指令提示）。

### 步驟 4：打造開發紀錄網頁與實測證明 (`index.html`)
* **目的**：課堂評量規定「在線上文字貼上 GitHub 與開發紀錄網頁連結，網頁附實測證明」。
* **特色功能**：
  * **內建擬真 LINE 對話模擬器**：直接在瀏覽器打字或點擊快捷按鈕，即可立即體驗 Bot 回應！
  * **完整實測證明表格**：詳細列出 3 個情境之輸入、預期與實際結果。
  * **一鍵輸出 PDF 簡報/計畫**：點擊右上角「🖨️ 匯出計畫/簡報 PDF」，自動隱藏非必要按鈕，排版出整齊的繳交格式。
