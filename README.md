# 大學生報告主題發想_搜集機器人 (IdeaCatcher Bot) - v2.0 課後改善版

專為大專院校學生設計的 LINE Bot，解決日常生活中有靈感冒出來但常因手邊沒工具或備忘錄散落而「點子飛掉」的困擾。提供即時記錄、智慧學科分類、精準檢索與單筆主題管理功能。

## 🚀 改善版 (v2.0) 核心亮點與前後版本差異

## 🔐 設定方式與安全金鑰佔位說明 (Environment Variables)

本專案遵守資訊安全規範，**絕無在程式碼、提交紀錄或網頁中放置真實金鑰**。若要串接至真實 LINE Developers 平台，請透過環境變數注入金鑰：

```bash
# 在本機或雲端主機設定環境變數（使用佔位文字說明）：
export LINE_CHANNEL_SECRET="YOUR_LINE_CHANNEL_SECRET_PLACEHOLDER"
export LINE_CHANNEL_ACCESS_TOKEN="YOUR_LINE_ACCESS_TOKEN_PLACEHOLDER"
```

教師或評審若需在本機測試，可直接執行本地測試腳本或 CLI 互動模式，無需任何付費或真實金鑰即可 100% 正常運作。

## 💻 本機使用方法與實測操作

### 1. 執行自動化測試腳本 (單元測試與實測報告)
```bash
cd /Users/juku1128/Documents/測試/嘻嘻
python3 test_bot.py
```
> 執行後將印出包含「輸入內容、預期結果、實際結果」的實測報告，5 項測試全數通過（PASS ✅）。

### 2. 啟動命令列互動測試模式
```bash
python3 bot.py
```
在終端機中可直接輸入以下指令測試：
* **智慧記錄**：`靈感：深度學習在無人機的應用`（自動歸類為資訊科技）
* **指定分類**：`靈感：消費者心理學 分類：商管企管`
* **分類篩選**：`查看：資訊科技` 或 `搜尋：心理`
* **調閱全部**：`查看靈感`
* **單筆刪除**：`刪除：1`
* **防呆測試**：`刪除：99` 或 `靈感：`

### 3. 開啟開發紀錄網頁與擬真 LINE 模擬器
```bash
open index.html
```
* **LINE 互動模擬器**：網頁右側可直接打字或點擊快速按鈕進行實測。
* **成果簡報**：點擊右上角「🖨️ 匯出成果簡報/計畫 PDF」，即可一鍵匯出標準 5 頁簡報。

## 🤖 AI 協作與檢查修正經驗

* **AI 代理工具**：Antigravity Agent (Gemini 3.8 Flash High 模型)
* **代表性指令**：
  > 「請依照我的 LINE Bot 專題資料，升級 bot.py 加入智慧關鍵字自動分類、領域篩選與單筆刪除功能，並加入嚴格的防呆捕捉與自動化測試腳本。」
* **檢查或修正 AI 產出的關鍵經驗**：
  * **發現問題**：在最初請 AI 產生單筆刪除邏輯時，AI 僅實作了單純的 `ideas.pop(index)`，未對使用者輸入進行型態與範圍檢驗。當在終端機實測輸入 `刪除：99` 或 `刪除：abc` 時，程式直接拋出 `IndexError` 與 `ValueError` 導致機器人當機！
  * **檢查與修正**：主動要求 AI 增補 `try-except ValueError` 與 `target_idx > len(ideas)` 的邊界條件判斷，將錯誤轉化為友善的「提示目前有效範圍」警示，成功解決崩潰問題。
