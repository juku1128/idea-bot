# 大學生報告主題發想_搜集機器人 (IdeaCatcher Bot) - v2.0 課後改善完成版

專為大專院校學生設計的 LINE Bot，解決日常生活中有靈感冒出來但常因手邊沒工具或備忘錄散落而「點子飛掉」的困擾。提供即時記錄、智慧學科分類、精準檢索，以及**「一鍵生成三段式 Markdown 報告大綱草稿」**！

## 🔐 設定方式與安全金鑰佔位說明 (Environment Variables)

## 💻 本機使用方法與實測操作

### 1. 執行自動化測試腳本 (單元測試與實測報告)
```bash
cd /Users/juku1128/Documents/測試/嘻嘻
python3 test_bot.py
```
> 執行後將印出包含「輸入內容、預期結果、實際結果」的實測報告，5 項測試全數通過（PASS ✅）。

### 2. 啟動命令列互動測試模式
```bash
python3 bot.py
```
在終端機中可直接輸入以下指令測試：
* **🌟 一鍵生成報告大綱**：`大綱：1`（會即時印出結構化大綱，並在資料夾自動產生實體 `.md` 檔案！）
* **智慧記錄**：`靈感：深度學習在無人機的應用`（自動歸類為資訊科技）
* **指定分類**：`靈感：消費者心理學 分類：商管企管`
* **分類篩選**：`查看：資訊科技` 或 `搜尋：心理`
* **調閱全部**：`查看靈感`
* **單筆刪除**：`刪除：1`
* **防呆測試**：`大綱：99` 或 `刪除：99`

### 3. 開啟開發紀錄網頁與擬真 LINE 模擬器
```bash
open index.html
```
* **LINE 互動模擬器**：網頁右側設有【🌟 1. 生成大綱】等快速按鈕，可直接現場點擊驗證！
* **成果簡報**：點擊右上角「🖨️ 匯出成果簡報/計畫 PDF」，即可一鍵匯出標準 5 頁簡報。

## 🤖 AI 協作與真實檢查修正經驗

* **AI 代理工具**：Antigravity Agent (Google DeepMind)
* **代表性指令**：
  > 「請依照我的 LINE Bot 專題資料，實作一鍵生成 Markdown 報告大綱草稿功能，並加上智慧關鍵字自動分類、防呆捕捉與自動化單元測試。」
* **檢查或修正 AI 產出的真實經驗（重要評量重點）**：
  1. **真實經驗 1：修正 Git 初始化與目錄架構**  
     最初 AI 在背景嘗試直接執行 `git add`，但遇到 macOS 沙盒權限確認。我察覺此資料夾應全新獨立管理，因此按下拒絕，並主動指示 AI「GIPINIT這個新的資料夾」，促使 AI 在獨立的「嘻嘻」資料夾中重新建立乾淨的 Git 倉庫，並於外層加入 `.gitignore` 隔離，有效避免專案衝突。
  2. **真實經驗 2：精準聚焦改善項目，拒絕過度複雜規劃**  
     AI 先前曾列出「串接 LINE Messaging API 與 Webhook 雲端部署」等未來項目，我及時審查並明確指出「該項目未討論且過於困難，本作業應交付改版完成品」，並指定實作「一鍵匯出 Markdown 報告大綱草稿」，讓專案精準聚焦在最有價值的實用功能上。
  3. **真實經驗 3：堅持真實性原則，杜絕虛構**  
     我特別要求 AI：「裡面的內容若有缺漏請不要自行編造，請詢問我讓我補上。」促使 AI 主動全面盤點專案中的外部連結、姓名學號與個人心得，凡未確認者一律標註「待補」，落實了嚴謹求實的工程態度。

## ⚠️ 現行作品限制與下一步規劃

### 現行限制 (Current Limits)
1. **通訊串接層次**：目前以本機 Python CLI 與 Web 前端模擬器呈現，尚未向 LINE 官方申請付費企業 Webhook 伺服器部署。
2. **大綱生成機制**：目前對於大綱的判斷還未變成自動 AI 智慧導入，而是有一個固定版本，當偵測到該領域關鍵字就會給出固定的大綱格式。

### 下一步 (Next Steps)
1. **研究如何將網頁做成 LINE Bot**：進一步探索如何將現有的網頁模擬器與後端邏輯串接至真實手機 LINE 平台。
2. **擴充多元關鍵字庫**：引入更多相關關鍵字，讓 AI 可以更多元自動判斷靈感的學術分類與適合的大綱。
